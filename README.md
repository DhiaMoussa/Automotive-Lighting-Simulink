# Automotive-Lighting-Simulink
Modélisation et simulation d'un système d'éclairage automobile avec MATLAB/Simulink. Conception des lois de commande logiques pour les phares, clignotants, feux de position et de freinage. Simulation de différents scénarios de fonctionnement afin d'analyser les réactions du système et d'appliquer les principes de l'électronique automobile.
